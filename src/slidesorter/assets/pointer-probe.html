Pointer diagnostics

A deliberately small test surface for the Chrome/macOS case where hover stops updating after another window receives focus.

Local and temporary. This page reads browser pointer and focus events only. It does not inspect media, paths, settings, or collection state, and makes no network requests.

  1. Move among the pads. The CSS and JavaScript indicators should follow.
  2. Click another application window, such as Mail.
  3. Return by clicking this page’s heading—not by leaving and re-entering Chrome.
  4. Move directly across the pads while the pointer stays inside Chrome.
  5. If counters freeze and neither indicator follows, the browser failure is captured.
