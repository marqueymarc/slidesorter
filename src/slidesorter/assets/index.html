Manual only. Checking contacts GitHub’s release service; no media, paths, thumbnails, or SlideSorter state are sent.

How to updateHomebrew

For a Homebrew install, use this command when you want to update SlideSorter. It does not touch your collection.

brew update && brew upgrade slidesorter

Installed another way? See the installation guide for pipx, source, and container updates.
